# Перед публикацией

Используйте тестовый мир и отдельные подключения ведущего и игрока.

- [ ] Shift+H открывает окно, поиск и памятки работают.
- [ ] Персонаж игрока виден в выборе отправителя; чужим персонажем распорядиться нельзя.
- [ ] Передача героя: предложение, принятие, отклонение, нулевой запас и полный получатель.
- [ ] +1: обычный провал на единицу, отсутствие кнопки при нуле очков, сохранение исходного d20 и смена результата.
- [ ] Скрытые КС и слепые проверки не раскрывают игроку сведения через кнопку.
- [ ] Переброс обычного и критического урона с несколькими типами; лечение; отмена подтверждения; сохранение приватности сообщения.
- [ ] Подарок Злодея: у ведущего +1, у героя без изменений.
- [ ] Обмен: у ведущего +1 Злодея, у героя +1 Героя; полные запасы блокируют принятие.
- [ ] Повторное принятие одного предложения ничего не добавляет.
- [ ] «Начало сессии» восстанавливает 1 только при нуле; перезагрузка не увеличивает запас.
- [ ] Состояние и запросы сохраняются после перезапуска.
- [ ] Согласованы ограничения, перечисленные в README.

Этот список — план ручной проверки, а не заявление, что все пункты уже пройдены.
