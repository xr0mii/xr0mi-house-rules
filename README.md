# Домашние правила xr0mi

Личные домашние правила xr0mi для **Foundry VTT 14 / Pathfinder 2e 8.6.1+**.

## Что добавляет

- Покупку **+1 за Очко Героя**, когда до обычного успеха не хватает единицы.
- Переброс урона и лечения за Очко Героя через меню сообщения в чате.
- Передачу Очков Героя между персонажами с подтверждением ведущего.
- Общий запас Очков Злодея **0–3**, подарки и обмен «ведущему +1 Злодея, персонажу +1 Героя».
- Памятки действий и свод домашних правил с поиском, включая правила ритуалов.

## Как пользоваться

**Shift+H** открывает передачу очков, подарки, обмены, памятки и свод правил. Предложения принимает ведущий кнопками в чате.

Кнопка **+1** появляется у подходящего броска. Переброс урона и лечения доступен по правой кнопке на сообщении; новый результат заменяет старый. Если старый результат уже применён к здоровью, сначала отмените его применение.
