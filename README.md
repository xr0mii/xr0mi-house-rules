# Домашние правила xr0mi

Русскоязычный модуль для **Foundry VTT 14 / Pathfinder 2e 8.6.1+**: Очки Героя и Злодея, обмены между участниками, памятки и свод домашних правил Руслана (xr0mi).

**Статус: ранняя публичная версия 0.4.1.** Это набор правил конкретного стола, а не официальные правила PF2e. Поддержка других систем и Foundry 13 не заявлена. Совместимость со всеми сторонними модулями не проверена.

## Возможности

- **+1 за Очко Героя:** при обычном провале атаки, навыка или спасброска ровно на единицу ниже КС появляется кнопка покупки успеха. Она списывает очко, сохраняет d20, повышает итог и меняет результат на успех. Без очков кнопки нет. Тайные проверки исключены; при скрытых КС или результатах предложение видит только ведущий.
- **Переброс урона и лечения:** пункт в контекстном меню сообщения. За одно очко перебрасываются все поддерживаемые DamageRoll в сообщении; используется второй результат, даже если он хуже. Повторная покупка переброса этого сообщения запрещена.
- **Передача Очка Героя:** игрок отправляет запрос, активный ведущий подтверждает его в чате. Лимиты и права проверяются повторно при подтверждении.
- **Очки Злодея:** общий запас ведущего 0–3, сохранение между сессиями, подарок или сделка «ведущему +1 Злодея, персонажу +1 Героя». Подарки и сделки требуют согласия ведущего.
- **Памятки и правила:** поиск по своду, карточки Помощи, помощи подняться и снятия продолжительного урона.

Отдельных зависимостей, кроме системы PF2e, нет. Настройка Galactic Hero Points не включается этим модулем.

## Установка

После публикации первого релиза вставьте этот адрес в поле **Manifest URL** при установке модулей Foundry:

```text
https://github.com/xr0mii/xr0mi-house-rules/releases/latest/download/module.json
```

Включите **«Домашние правила xr0mi»** в нужном мире PF2e. Установка и настройка выполняются отдельно для каждого мира.

Для ручной установки распакуйте содержимое `xr0mi-house-rules.zip` в `Data/modules/xr0mi-house-rules/`. Файл `module.json` должен оказаться непосредственно внутри этой папки. Затем перезапустите Foundry. При обновлении замените файлы модуля и обновите страницы всех участников.

## Использование

Откройте окно сочетанием **Shift+H** или через **Настройки игры → Настроить параметры → Домашние правила xr0mi**.

В окне выберите своего персонажа для передачи очка, подарка или обмена. Ведущий принимает или отклоняет предложение кнопками в чате. До подтверждения ресурсы не меняются. Передавать очки для Геройского восстановления запрещено домашними правилами; применимость проверяет ведущий.

Покупка +1 доступна непосредственно у подходящего броска. Переброс урона и лечения — через правую кнопку мыши по сообщению. Обычный переброс d20 и Геройское восстановление остаются штатными функциями PF2e.

У ведущего есть кнопки изменения запаса Очков Злодея. **«Начало сессии»** добавляет одно очко только при нуле. При первом включении запас равен нулю: выставьте фактическое значение кнопкой **«Добавить 1»**. Переподключение и перезагрузка очков не выдают.

Для панели макросов можно создать макрос типа Script:

```js
game.modules.get('xr0mi-house-rules').api.open();
```

## Важные ограничения

- Если урон или лечение уже применены к здоровью, отмените применение перед перебросом. Модуль обновляет бросок, но не пересчитывает здоровье целей.
- Покупка +1 не отменяет ранее применённые последствия провала. Заметки карточки, зависящие от старого исхода, удаляются; новые последствия применяются участниками вручную.
- «Потратить 1» Очко Злодея учитывает расход ресурса. Автоматический переброс врага за него пока не реализован.
- Знания, исследование, Помощь и другие правила из справочника не автоматизированы, если это прямо не указано выше. Свод не означает, что модуль включает все перечисленные в нём варианты.
- Операции с очками одного персонажа из разных клиентов одновременно не являются общей атомарной транзакцией. При ошибке проверьте запасы; при частичном сбое модуль пытается вернуть списанное.
- Очки Злодея сохраняются в настройках мира. Запросы, отметки перебросов и покупок хранятся во флагах сообщений чата. Внешняя отправка данных модулем не реализована.

## Проверка и обратная связь

Автоматические проверки покрывают права, лимиты, подарки и обмены, повторную обработку, сбои записи, степени успеха, сохранение d20, скрытые проверки и перебросы. Интерфейс проверялся отдельно в браузерном стенде. Полную многопользовательскую проверку в Foundry они не заменяют.

Перед первой игровой сессией используйте [короткий список проверки](docs/TESTING.md). Для сообщения об ошибке откройте Issue и укажите версии Foundry, PF2e, модуля и шаги воспроизведения. Не прикладывайте пароли и полный архив мира.

## Разработка и выпуск

Достаточно Node.js 22+ и Python 3. Устанавливать npm-пакеты не требуется:

```sh
node tools/check.mjs
node tools/test.mjs
python tools/build.py
```

Результат сборки — `dist/xr0mi-house-rules.zip`, `dist/module.json` и контрольные суммы. Инструкция выпуска: [RELEASING.md](docs/RELEASING.md).
